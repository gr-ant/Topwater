Topwater gives an LLM agent one bash tool backed by a simulated Linux shell: an in-process interpreter, an in-memory Ubuntu-like filesystem with users and permissions, about 110 standard commands, and resource limits.

This page runs the TypeScript port entirely in your tab, in a Web Worker. Nothing you type or upload is sent anywhere: no model, no API keys, no server.

Watch an agent's session turn by turn in the recording viewer.

GitHub · NuGet (the .NET library: dotnet add package Topwater --prerelease)

What doesn't work here

No host programs or MCP servers (a browser has no processes). The api command could only reach CORS-enabled APIs and isn't set up in this demo.
